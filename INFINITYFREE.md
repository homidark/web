# InfinityFree Static Site Upload

The static site files are in the `infinityfree` folder. This folder contains HTML, CSS, JavaScript, and the process illustration; it does not include the Python login or owner dashboard.

## Publish on InfinityFree

1. Create or sign in to a free account at `https://dash.infinityfree.com/`.
2. Create a free hosting account and choose one of the available free subdomains, or connect a domain you own.
3. Open the hosting account's File Manager and open the `htdocs` web root.
4. Upload the four files from the `infinityfree` folder directly into `htdocs`: `index.html`, `app.js`, `styles.css`, and `process-flow.svg`.
5. Open the site URL shown in the InfinityFree dashboard.

InfinityFree serves this as a static website. The built-in sign-in, account creation, owner dashboard, and server-side editing are not available in this version. The hosting account may have service limits; review the current InfinityFree terms and dashboard notices.
